1. Первый раздел
# Введение
Markdown — это простой язык текстовой разметки, созданный в 2004 году. Его главная цель — позволить людям писать легко читаемый и легко редактируемый текст, который можно быстро превратить в красивый HTML-код. В отличие от сложных текстовых редакторов (вроде MS Word), Markdown не отвлекает вас на меню и кнопки — вы форматируете текст прямо во время печати с помощью обычных символов (звездочек, решеток и дефисов).

# Основные возможности Markdown
Markdown поддерживает все базовые элементы форматирования, которые нужны для оформления заметок, статей или документации:
• Заголовки: создаются с помощью символа # перед текстом (от # Заголовок 1 до ###### Заголовок 6).
• Выделение текста: текст можно сделать курсивом (окружив его одиночными звездочками *текст*) или жирным (двойными звездочками **текст**).
• Списки: маркированные списки создаются с помощью дефиса или звездочки (* элемент), а нумерованные — обычными цифрами с точкой (1. элемент).
• Ссылки и фото: ссылка оформляется как [Текст](ссылка), а изображение — так же, но с восклицательным знаком в начале: ![Описание](ссылка).
